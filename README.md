# Aurum Estate — AI Lead Qualification & Follow-Up System

A multi-agent n8n workflow built for a real estate client to eliminate slow, manual lead follow-up.

## Problem
Inbound leads from Facebook and Zillow ads were sitting unattended for hours before an agent responded — resulting in lost deals to faster-moving competitors.

## Solution
Built a multi-agent automation system that:
- Captures leads instantly via webhook
- Uses an AI agent to qualify each lead (Hot / Warm / Cold) based on intent signals
- Routes hot leads to the right agent in real time
- Triggers automated, personalized follow-up sequences for warm/cold leads
- Logs everything to a central CRM/sheet for tracking

## Result
Response time dropped from hours to under 60 seconds.

## Stack
n8n · OpenAI (GPT) · Google Sheets/CRM · Webhooks · Gmail/Email automation
